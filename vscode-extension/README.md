# 개인 비서 대시보드 (VSCode 확장)

대시보드를 VSCode 안 탭(Simple Browser)으로 연다.

- **열기 버튼**: 탭 줄 오른쪽 위 아이콘 · 아래 상태 줄 **비서** · `Ctrl+Alt+D` · 명령 팔레트 **비서: 대시보드 열기**.
  엔진이 꺼져 있으면 비서 폴더 창에서는 '비서: 자동 감시' 작업으로 켠 뒤 연다.
- 저절로 열지 않는다 (VSCode 를 열 때도). 닫아도 다시 열지 않는다.

설치: 비서 폴더에서 `bin/pa vscode-ext` → VSCode 에서 `Ctrl+Shift+P` → **Developer: Reload Window**.
