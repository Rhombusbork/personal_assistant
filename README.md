# Personal Assistant

개인 최적화 비서 프로그램.

## 목표 (3단계 구현)

1. **일정/할 일 관리**
2. **에이전틱 자동화된 할 일 수행**
3. **컨디션/스트레스 관리**

## 1단계: 일정/할 일 관리 — 관리 대상

| 분류 | 내용 |
|---|---|
| 정기적으로 해야 하는 것 | 과제 및 온라인수업 듣기 |
| 내가 추가하면 기억해줘야 하는 것 | 일정들 (예: 약속, 회의 등) |
| 기록해줘야 하는 것 | 수업시간 |
| 그 외 하고 싶은 일들 | 장기적인 todo로서 기록 |

## 진행 상황

- [ ] 1단계: 일정/할 일 관리
- [ ] 2단계: 에이전틱 자동화된 할 일 수행
- [ ] 3단계: 컨디션/스트레스 관리
