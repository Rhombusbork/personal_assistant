## 2. [오늘] 보기 — 타임라인

```
 ▶ 지금 ─────────────────────────────────────────────
 ┃ 14:00–14:50  생약학Ⅰ · 11주차 근류-1          [강의]
 ┃              마감 11/16(월) 12:00
 ┃   [▶ 강의 열기]  [📄 자료]  [✓ 들었음]
 ──────────────────────────────────────────────────
 ○ 15:00–18:00  🏫 약학실습                        (수업)
 ○ 19:00–20:00  유기약화학Ⅱ · Ch22 배움노트        [과제]
                마감 11/15(일) D-3
     [✍ 보고서 작성]  [📄 자료]  [Canvas]  [✓]  [✕ 제외]
   ┄┄ 빈 시간 20:10–23:00 (2시간 50분) ┄┄
 ✓ 11:49–12:49  리바이어던 텍스트 제출  (완료 · 흐리게)
```

- 맨 위 **"지금"** 카드: 지금 해야 할 일 하나. 없으면 "다음: 19:00 Ch22 배움노트"
- 수업·약속도 같은 줄에 섞어서 하루 흐름을 한눈에 본다
- 끝난 일은 흐리게 아래로. 놓친 일은 "⏭ 다른 시간으로 옮겨짐" 표시
- **빈 시간** 줄을 보여 준다 (나중에 "여기에 하고 싶은 일 넣기" 기능으로 확장할 수 있음)
- 내일 미리보기: 맨 아래 "내일: 수업 2, 할 일 4" 한 줄

## 4. 항목 종류별 버튼

| 종류 | 버튼 |
|---|---|
| 강의 | ▶ 강의 열기 · 📄 자료 · ✓ 들었음 |
| 퀴즈 | ▶ 퀴즈 열기 · 📄 자료 · ✓ |
| 과제 | ✍ 보고서 작성 · 📄 자료 · Canvas · ✓ · ✕ 제외 |
| 직접 넣은 할 일 | ✓ · ✏ 고치기 · 🗑 삭제 |
| 하고 싶은 일 | ✓ · 📅 날짜 정하기 · 🗑 |

- ▶ 강의·퀴즈·Canvas 열기: **Windows 브라우저**로 연다. 학교 로그인이 거기에 있고, Canvas는 VSCode 안 브라우저 탭에 넣으면 막힐 가능성이 크다
- 버튼이 많아 보이면 기본은 가장 중요한 것 하나만 보이고 나머지는 마우스를 올리면 나타나게 할 수도 있다

## 5. 📄 자료 버튼

1. 과목 → `~/study_system/materials/<영문 과목명>/` (CLAUDE.md 의 과목 대응표)
2. 항목 제목에서 단서를 뽑아 파일 이름과 맞춘다: `17강`, `Ch24`, `11주차`, `근류` 같은 단어
3. 맞는 파일이
   - 하나 → 바로 VSCode 편집기 탭으로 연다 (PDF 는 설치된 PDF 확장으로 보임)
   - 여러 개 → 작은 목록에서 고른다
   - 없음 → "자료 없음 — 다운로드 필요" (나중에 자료 다운로드 에이전트와 연결)
- 파일 열기는 엔진이 `code <파일>` 을 실행하는 방식이라 **엔진이 VSCode 안에서 돌고 있어야** 한다

## 6. ✍ 보고서 작성 버튼 (준비 + 초안)

누르면 오른쪽 "🤖 작업" 칸에 진행 단계가 보인다.

| 단계 | 하는 일 | Claude |
|---|---|---|
| 1. 과제 읽기 | Canvas 과제 설명·배점·마감·제출 형식 가져오기 | ✗ |
| 2. 자료 모으기 | 그 과목 materials 의 관련 파일, study_system/notes 의 내 기록 찾기 | ✗ |
| 3. 파일 만들기 | `~/report/` 에 `2024115032_허영준_<과목>_<종류>_<번호>.md` (report 규칙, 번호는 기존 파일 보고 자동) | ✗ |
| 4. 초안 쓰기 | 내 구독의 Claude 가 뒤에서 (`claude -p`) report/CLAUDE.md 글쓰기 규칙 + 과제 설명 + 자료 + 내 노트로 초안 작성 | ✓ |
| 5. 열기 | 완성된 파일을 VSCode 편집기 탭으로 열고 "✅ 초안 완료" 표시 | ✗ |

- 초안에는 **내 생각이 들어가야 할 자리를 `[✍ 내 생각: ...]` 로 비워 둔다.** report 규칙의 "글쓴이의 생각이 보여야 한다" 원칙 때문이다
- 몇 분 걸린다. 그동안 다른 일을 해도 된다
- 이미 보고서 파일이 있으면 새로 만들지 않고 그 파일을 연다
- 더 다듬고 싶으면 오른쪽 Claude 채팅에서 "이 초안 고쳐줘"

## 7. 🤖 작업 칸 (에이전트 진행 상황)

- 보고서 초안, 자료 찾기, (나중에) 자료 다운로드·내용 정리 같은 **오래 걸리는 일의 상태**를 모아 보여 준다
- 상태: ⏳ 진행 중 / ✅ 완료 (누르면 결과 파일 열기) / ⚠️ 실패 (이유 표시)
- 끝난 작업은 하루 지나면 사라진다
