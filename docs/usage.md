# 사용법

## 매일 쓰는 법 (Claude 없이)

1. VSCode 에서 `assistant.code-workspace` 를 연다 → **엔진이 켜지고, 대시보드가 VSCode 탭으로 자동으로 열린다**
   (이미 대시보드 탭이 열려 있으면 새로 열지 않는다 — 탭이 30초마다 '열려 있음' 신호를 보냄)
   - **처음 한 번**: `Ctrl+Shift+P → Tasks: Manage Automatic Tasks → Allow Automatic Tasks`.
     VSCode 는 이 설정이 없으면 '자동 작업 허용?'을 한 번만 묻고, 그때 닫았으면 다시 묻지도 실행하지도 않는다.
     이 설정은 모든 폴더에 적용되지만, 실행은 '신뢰한 폴더'에서만 된다.
   - 자동으로 안 열리면 `Ctrl+Shift+P → 작업 실행 → 비서: 대시보드 열기`, 또는 브라우저에서 http://localhost:8765
2. **대시보드에서 바로 입력**
   - ➕ 할 일 추가: 제목, 마감 날짜·몇 시까지(비우면 23:59), 예상 시간, 분류, 매주 반복 요일
   - 💭 하고 싶은 일: 기한 없는 일을 오른쪽 위 칸에 한 줄로 추가
   - 각 항목 옆 ✓ 완료 / ✕ 계속 제외(Canvas 과제) / 🗑 삭제(직접 넣은 할 일)
   - 30초마다 자동 갱신, '지금'은 컴퓨터 시계 기준. 계획은 15분마다 다시 짠다
3. 대시보드 입력은 모두 **[inbox.md](../inbox.md)** 에 적힌다 — inbox.md 를 직접 고쳐도 같다
4. [TODAY.md](../TODAY.md) (`Ctrl+Shift+V`) 는 같은 내용을 글로 요약한 것

대시보드 오른쪽 위 표시가 **실시간**이면 입력 가능, **보기 전용**이면 감시기가 꺼진 상태다.

## 대시보드 기능 (R1·R2)

- **빠른 입력** (`/` 또는 Ctrl+K): `린스타트업 발표 @금 18시 ~2h #창업` — `@오늘 @내일 @모레 @월~@일`, `18시`/`18:00` 가능.
  날짜 없이 쓰면 💭 하고 싶은 일
- **[오늘] / [주차별]** 두 탭 (`t` / `w` 키), 마지막 보기를 기억.
  - [주차별]: ◀ ▶ (또는 ← → 키)로 주 이동, 위의 **학기 띠**(1~17주, 일이 많은 주일수록 진하게, '시험' 표시)를 누르면 그 주로.
    그 주의 캘린더(지난 요일은 흐리게) + **그 주에 마감인 것** 목록 — 종류별로 묶고 버튼은 항상 보인다
  - 강의: **▶ 수업 접속 · 📄 자료 · 🤖 내용정리**(자료 PDF 의 핵심 정리를 만들거나, 있으면 연다) · ⏱ · ✓
  - 과제: **✍ 보고서 작성** · 📄 자료 · Canvas · ⏱ · ✓ · ✕
  - 계획 블록은 2주 앞까지만 만들므로, 더 먼 주는 캘린더 없이 목록만 보인다
- 💭 하고 싶은 일의 **📅 오늘** 버튼: 오늘 마감을 붙여 오늘 빈 시간에 넣는다
- 항목 버튼: ▶ 열기(Windows 브라우저) · 📄 자료 · ⏱ 시작 · ✓ 완료 · ✕ 제외 / 🗑 삭제
- **⏱ 시간 기록**: 시작 → [✓ 끝내고 완료] 또는 [■ 멈춤]. 기록은 통계의 '오늘 실제로 한 시간'에 쌓이고, 나중에 예상 시간 보정에 쓴다
- **📄 자료**: `17강`·`Ch24`·`11주` 같은 단서로 `study_system/materials/<과목>` 의 파일을 찾아 VSCode 탭으로 연다
- **📥 새로 받은 파일**: Windows 다운로드 폴더에 자료가 생기면 과목을 추측해 보여 주고, [옮기기] 한 번으로 과목 폴더로

## 강의 플랫폼(LearningX) 연결 (R7)

`bin/pa browser login` 으로 한 번 로그인해 두면 (로그인 정보는 `data/` 에만, git 제외) Canvas 확인 때:
- **배포 자료 PDF 를 과목 materials 폴더로 자동 다운로드** (이미 있는 건 건너뜀, 교수자가 지운 자료는 받지 않음)
- 강의의 **실제 길이·실제 출석 마감**을 쓰고, **수강을 마치면 자동으로 완료**
- 지난 주차라도 안 들은 강의는 지각 수강 기간이 남았으면 할 일에 "(지각 수강)" 으로 추가

강의·자료 **페이지를 열지 않고** 데이터만 읽는다 (열람·출석 기록이 남지 않게).
로그인이 만료되면 **비서가 스스로 다시 로그인하지 않고** 자료 다운로드·수강 확인만 잠시 멈춘다.
대시보드에 "LearningX 로그인 필요" + **[다시 로그인]** 버튼 (누를 때만 로그인 창이 열림).

> ⚠️ 학교 시스템은 로그인을 하나만 유지하는 것으로 보인다. 비서용으로 로그인하면 **평소 브라우저에서
> 강의 영상·자료가 안 열릴 수 있다** (2026-11-12 실제로 겪음, 시크릿 창은 정상).
> → 평소 브라우저에서 Canvas 로그아웃 후 다시 로그인 (안 되면 `jejunu` 사이트 쿠키 삭제 후 로그인).

## 계획이 똑똑해지는 부분 (R5)

- ⏱ 기록이 같은 종류·과목에서 3번 쌓이면 예상 시간을 자동 보정 (통계 → 예상 시간 보정)
- 이미 ⏱ 로 한 시간은 남은 시간에서 뺀다
- 2시간 넘는 과제·할 일은 90분 이하로 나눠 여러 날에 (`split_over`, `chunk_minutes`)
- 블록마다 "왜 여기?" 이유, 머리글에 "이번 주 여유/부족"

## inbox.md 문법

```markdown
## 할 일
- [ ] 리바이어던 발표자료 제출 @11-20 ~2h        마감 11/20 23:59, 예상 2시간
- [ ] 린스타트업 발표 @11-13 18:00 ~90m #창업     마감 시각, 과목
- [ ] 생화학 공부 ~1h 매주:화,목                  매주 그 요일 안에
- [ ] 논문 읽기                                    기한 없음 (장기 할 일)
- [x] 린스타트업 텍스트 제출 @11-11                체크 = 완료, 체크 풀면 다시 열림

## 완료
- m2890903                    키(TODAY.md 의 `...`)나 제목 단어 — 한 번 처리되면 지워도 완료 유지

## 제외
- 생약학 조별학습활동          여기 있는 동안 계속 제외 — 지우면 다시 나타남
```

- 반복 할 일 하나를 완료하려면 `## 완료` 에 날짜 붙은 키를 적는다: `i:생화학 공부@11-12`
- Canvas 과제·퀴즈는 **제출하면 자동으로 완료**된다 (조장 대표 제출 포함). 강의는 들은 뒤 `## 완료` 에 적는다.

## 명령 (`bin/pa`)

| 명령 | 하는 일 |
|---|---|
| `bin/pa watch` | 자동 감시 + 대시보드 서버 http://localhost:8765 (VSCode 를 열면 자동 실행됨) |
| `bin/pa run [--full]` | 한 번 실행: inbox → (`--full` 이면 Canvas·과제 캘린더) → 계획 → TODAY.md·대시보드 |
| `bin/pa list` | 남은 할 일 (맨 앞이 키) |
| `bin/pa done/ignore/unignore <키>` | 완료 / 계속 제외 / 제외 취소 |
| `bin/pa time <키> <분>` | 예상 소요 시간 조정 |
| `bin/pa plan [--dry-run]` | 계획만 다시 |
| `bin/pa lectures [과목] [--open N]` | 이번 주 강의 목록·열기 |
| `bin/pa browser login` | 학교 로그인 저장 (LearningX 연결) |

VSCode 에서 `Ctrl+Shift+P → 작업 실행 → 비서: 지금 전체 동기화` 로도 실행할 수 있다.

## 계획 규칙 (`config/timetable.yaml` 의 `planner`)

- 마감이 가까운 순으로, 월·수·금·토 빈 시간에 먼저 배치하고 부족하면 일요일, 그래도 없으면 나머지 요일
- 대면 수업·약속(Google Calendar) 시간은 피함, 하루 최대 `max_minutes_per_day`
- 같은 과목의 퀴즈·과제는 그 과목 강의 뒤, 이미 시작한 블록은 고정

## 데이터

- `data/pa.db` (SQLite): `tasks` 할 일, `events` 자동 기록, `plan` 현재 계획, `busy` 수업·약속
- 모두 git 제외. 대시보드 데이터 `dashboard/data.js` 도 자동 생성·git 제외.
