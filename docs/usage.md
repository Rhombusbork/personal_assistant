# 사용법

## 매일 쓰는 법 (Claude 없이)

1. VSCode 에서 `assistant.code-workspace` 를 연다 → **엔진이 켜지고, 대시보드가 VSCode 탭으로 자동으로 열린다**
   (이미 대시보드 탭이 열려 있으면 새로 열지 않는다 — 탭이 30초마다 '열려 있음' 신호를 보냄)
   - **처음 한 번**: `Ctrl+Shift+P → Tasks: Manage Automatic Tasks → Allow Automatic Tasks`.
     VSCode 는 이 설정이 없으면 '자동 작업 허용?'을 한 번만 묻고, 그때 닫았으면 다시 묻지도 실행하지도 않는다.
     이 설정은 모든 폴더에 적용되지만, 실행은 '신뢰한 폴더'에서만 된다.
   - 자동으로 안 열리면 `Ctrl+Shift+P → 작업 실행 → 비서: 대시보드 열기`, 또는 브라우저에서 http://localhost:8765
2. **대시보드에서 바로 입력**
   - ➕ 할 일 추가: 제목, 마감 날짜·몇 시까지(비우면 23:59), 예상 시간, 분류, 매주 반복 요일
   - 💭 하고 싶은 일: 기한 없는 일을 오른쪽 위 칸에 한 줄로 추가
   - 각 항목 옆 ✓ 완료 / ✕ 제외(Canvas 과제 — **[이것만]** 또는 **[앞으로도]**: 같은 과목·이름의 과제가 또 생겨도 계속) / 🗑 삭제(직접 넣은 할 일)
   - 오른쪽 **🚫 제외한 것** 을 펼치면 제외 목록과 **[취소]** — 취소하면 다시 나타난다 (휴대폰에서도 됨)
   - 30초마다 자동 갱신, '지금'은 컴퓨터 시계 기준. 계획은 15분마다 다시 짠다
3. 대시보드 입력은 모두 **[inbox.md](../inbox.md)** 에 적힌다 — inbox.md 를 직접 고쳐도 같다
4. [TODAY.md](../TODAY.md) (`Ctrl+Shift+V`) 는 같은 내용을 글로 요약한 것

대시보드 오른쪽 위 표시가 **실시간**이면 입력 가능, **보기 전용**이면 감시기가 꺼진 상태다.

## 대시보드 기능 (R1·R2)

- **빠른 입력** (`/` 또는 Ctrl+K): `린스타트업 발표 @금 18시 ~2h #창업` — `@오늘 @내일 @모레 @월~@일`, `18시`/`18:00` 가능.
  날짜 없이 쓰면 💭 하고 싶은 일
- **[오늘] / [주차별]** 두 탭 (`t` / `w` 키), 마지막 보기를 기억.
  - [주차별]: ◀ ▶ (또는 ← → 키)로 주 이동, 위의 **학기 띠**(1~17주, 일이 많은 주일수록 진하게, '시험' 표시)를 누르면 그 주로.
    그 주의 캘린더(지난 요일은 흐리게) + **그 주에 마감인 것** 목록 — 종류별로 묶고 버튼은 항상 보인다
  - 강의: **▶ 수업 접속 · 📄 자료 · 🤖 내용정리**(자료 PDF 의 핵심 정리를 만들거나, 있으면 연다) · 🧩(퀴즈 요청 복사) · ⏱ · ✓
  - 과제: **✍ 보고서 작성** · 📄 자료 · Canvas · ⏱ · ✓ · ✕
  - 계획 블록은 2주 앞까지만 만들므로, 더 먼 주는 캘린더 없이 목록만 보인다
- 💭 하고 싶은 일의 **📅 오늘** 버튼: 오늘 마감을 붙여 오늘 빈 시간에 넣는다
- 항목 버튼: ▶ 열기(Windows 브라우저) · 📄 자료 · ⏱ 시작 · ✓ 완료 · ✕ 제외 / 🗑 삭제
- **⏱ 시간 기록**: 시작 → [✓ 끝내고 완료] 또는 [■ 멈춤]. 기록은 통계의 '오늘 실제로 한 시간'에 쌓이고, 나중에 예상 시간 보정에 쓴다
- **📄 자료**: 할 일마다 자료를 골라 **연결**해 두는 창 (아래 "자료 연결"). 연결된 게 하나면 바로 열린다.
  자료가 연결된 항목에는 **📎n** 이 붙는다 (휴대폰에서는 눌러서 파일 이름만)
- **📥 새로 받은 파일**: Windows 다운로드 폴더에 자료가 생기면 과목을 추측해 보여 주고, [옮기기] 한 번으로 과목 폴더로

## 자료 연결 (📄 자료 창)

할 일마다 "연결된 자료"를 두면 ✍ 보고서 작성·🤖 내용정리·🧩 퀴즈 요청이 **그 자료를 먼저** 쓴다.
연결이 없으면 예전처럼 제목의 단서(`17강`·`Ch24`·`11주`)로 추측한다. Claude 는 쓰지 않는다 (파일 이름만 다룸).

| 하는 법 | 설명 |
|---|---|
| 칩 | 연결된 자료. 누르면 열림 · PDF 는 🤖(요약 만들기) 또는 📝(만든 요약 열기) · ✕ 빼기 · ⚠️ 파일 없음이면 [다시 찾기] |
| 추천 | ⭐ 제목 번호가 맞는 자료·노트, 그 과목 최근 파일 — 누르면 연결 |
| 찾기 | 단어 몇 개 (모두 들어간 파일만, 파일 이름에서 맞은 것 먼저). `↑↓` 고르기 · `Enter` 연결 · `Esc` 지우기/닫기 |
| 경로 | `/` 를 치면 폴더 따라가기 (예: `자료/organic_chemistry/`). `Tab` = 채우기 (폴더면 한 단계 들어감) |
| 📁 둘러보기 | 그 과목 폴더에서 시작. 위 [자료][노트][보고서][📥 다운로드], 경로 줄, ⬆, 거르기, 이름순/최근순, 체크 → [선택한 n개 연결] |
| 📥 다운로드에서도 찾기 | Windows 다운로드 폴더 **맨 위, 최근 7일, 문서만**. 연결하면 **그 할 일의 과목 자료 폴더로 옮긴 뒤** 연결 (과목을 모르면 물어봄) |
| 🧩 퀴즈 요청 복사 | "/quiz 과목 제목 — 이 자료로 퀴즈 만들어줘 + 연결된 파일 목록" 이 복사됨 → Claude 채팅에 붙여 넣기 |

- 할 일 하나에 **파일을 하나씩 원하는 만큼** (최대 10개). 폴더째 연결은 없다
- 강의 플랫폼에서 받은 자료는 같은 주차의 강의와 **짝**으로 자동 연결된다 (🔗, 후보가 하나일 때만). 빼면 다시 넣지 않는다
- 찾기 범위: `~/study_system/materials`, `~/study_system/notes`, `~/report` (+ 버튼을 켰을 때만 다운로드).
  범위·확장자·최대 개수·다운로드 기간은 `config/materials.yaml` — **바꾸려면 채팅에서** 말하면 된다
- 채팅에서도: `bin/pa links <키>` 보기, `bin/pa link <키> <파일>` 연결, `bin/pa unlink <키> <파일>` 빼기

## 강의 플랫폼(LearningX) 연결 (R7)

`bin/pa browser login` 으로 한 번 로그인해 두면 (로그인 정보는 `data/` 에만, git 제외) Canvas 확인 때:
- **배포 자료 PDF 를 과목 materials 폴더로 자동 다운로드** (이미 있는 건 건너뜀, 교수자가 지운 자료는 받지 않음)
- 강의의 **실제 길이·실제 출석 마감**을 쓰고, **수강을 마치면 자동으로 완료**
- 지난 주차라도 안 들은 강의는 지각 수강 기간이 남았으면 할 일에 "(지각 수강)" 으로 추가

강의·자료 **페이지를 열지 않고** 데이터만 읽는다 (열람·출석 기록이 남지 않게).
로그인이 만료되면 **비서가 스스로 다시 로그인하지 않고** 자료 다운로드·수강 확인만 잠시 멈춘다.
대시보드에 "LearningX 로그인 필요" + **[다시 로그인]** 버튼 (누를 때만 로그인 창이 열림).

> ⚠️ 학교 시스템은 로그인을 하나만 유지하는 것으로 보인다. 비서용으로 로그인하면 **평소 브라우저에서
> 강의 영상·자료가 안 열릴 수 있다** (2026-11-12 실제로 겪음, 시크릿 창은 정상).
> → 평소 브라우저에서 Canvas 로그아웃 후 다시 로그인 (안 되면 `jejunu` 사이트 쿠키 삭제 후 로그인).
시간 초과 같은 일시적 오류는 "다음 확인 때 다시 시도"로만 표시된다.

## 공지 · 시험 · 요약 (R6·R8)

- **📢 새 공지**: Canvas 확인 때 새 공지를 모아 보여 준다 (코드만). [🤖 요약·제외 후보 찾기] 를 누르면 그때만 Claude 가
  공지마다 한 줄 요약 + "안 내도 될 것 같은 과제"를 제안 → [제외] / [아니요]
- **시험 모드**: 제목에 `시험`·`고사` 가 들어간 할 일 (예: `생화학 기말고사 @12-15 10시 #생화학`) →
  시험 7·4·2일 전부터 복습 1시간씩 3번 자동 배치 (`config/timetable.yaml` 의 `exam_review`).
  시험 자체는 공부 블록으로 잡지 않고, 마감 캘린더에 📝 로 알림
- **📝 시험 일정 후보**: 공지에 "기말고사 12월 15일 10시" 같은 문장이 있으면 (코드만) 오른쪽에 후보로 보여 준다 →
  [할 일로 추가] 또는 [아니요] (다시 안 물음). 확정은 사용자가 한다
- **🤖 요약**: 📄 자료 창의 PDF 칩 🤖, 또는 강의 옆 🤖 내용정리 → `materials/<과목>/요약/<이름>_요약.md`
  (내 노트 notes/ 와 섞지 않음). 연결된 PDF 가 여러 개면 자료 창이 열리고 고르게 한다
- **✍ 초안**: 과제 옆 버튼 → 과제 설명·**연결된 자료(없으면 추측한 자료)**·내 노트로 `~/report/` 에 규칙에 맞는 파일 + Claude 초안
  (내 생각 자리는 `[✍ 내 생각: …]` 으로 비워 둠). 이미 파일이 있으면 [새로 쓰기](지금 것은 `_old1` 로 보관) 또는 [열기]
- Claude 는 위 버튼을 눌렀을 때만 쓴다. 🤖 작업 칸에 몇 번 썼는지 표시

## 휴대폰에서 보기·입력 (GitHub Pages)

주소: **https://rhombusbork.github.io/personal_assistant/** (홈 화면에 추가하면 앱처럼 열림)

- PC 엔진이 바뀐 내용을 **최대 10분마다** 올린다 (바뀐 게 없으면 1시간에 한 번). 작업 스케줄러로도 하루 3번.
- 데이터는 **비밀번호로 잠겨** 올라간다. 비밀번호는 `.env` 의 `PA_MOBILE_PASSWORD` (바꾸면 다음 올릴 때부터 새 비밀번호, 휴대폰에서 다시 입력)
- 휴대폰에서 되는 것: 오늘/주차별 보기, 할 일·하고 싶은 일 추가, ✓ 완료, ✕ 제외, 🗑 삭제, 📅 오늘 하기, 수업·Canvas·퀴즈 링크 열기
- PC 에서만: 보고서 작성, 내용정리, 자료 열기, ⏱ 기록
- 휴대폰 입력은 GitHub 의 `phone-inbox` 브랜치에 (잠가서) 적히고, **PC 엔진이 3분마다** 가져가 반영 → 다음 올릴 때 화면에도 반영.
  PC 가 꺼져 있으면 켜질 때 반영된다
- 휴대폰에서 입력하려면 **GitHub 토큰을 한 번** 넣는다 (⚙):
  GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
  → Repository access: *Only select repositories* → `personal_assistant` → Permissions: **Contents: Read and write** → Generate
- 비서 코드는 올리지 않는다 (`gh-pages`·`phone-inbox` 브랜치만)

### 휴대폰 알림 (Google Calendar)

비서가 Google Calendar 에 넣는 일정에 알림을 붙인다 → **휴대폰 Google Calendar 앱이 알려 준다 (PC 가 꺼져 있어도)**.
- '학습 계획' 블록: 시작 **10분 전**
- **'마감' 캘린더**: 과제·퀴즈·온라인 강의 출석·직접 넣은 할 일 **모든 마감**에 **하루 전 · 3시간 전 · 1시간 전** 알림. 끝내거나 제외하면 자동으로 지워짐
- 바꾸려면 `config/timetable.yaml` 의 `reminders` (다음 동기화 때 모든 일정에 다시 적용). 0 이면 알림 없음
- 휴대폰 Google Calendar 앱 → 메뉴(☰)에서 **'학습 계획', '마감' 캘린더가 체크**되어 있어야 하고, 앱 알림이 켜져 있어야 한다

### 휴대폰 홈 화면에 앱처럼 두기 (처음 한 번)

**Android (Chrome)**
1. Chrome 으로 https://rhombusbork.github.io/personal_assistant/ 를 연다
2. 오른쪽 위 ⋮ → **홈 화면에 추가** (또는 "앱 설치") → 추가
3. 홈 화면의 **비서** 아이콘으로 열면 주소창 없이 앱처럼 열린다

**iPhone (Safari)**
1. Safari 로 같은 주소를 연다 (Chrome 이 아니라 Safari)
2. 아래 공유 버튼(□↑) → **홈 화면에 추가** → 추가

**처음 열 때**
1. 🔒 비밀번호 입력 → [열기]. 한 번 넣으면 그 휴대폰이 기억한다 (PC 의 `.env` 에 있는 `PA_MOBILE_PASSWORD`)
2. 입력까지 하려면 오른쪽 위 **⚙** → GitHub 토큰 붙여넣기 (위 "GitHub 토큰" 만드는 법). 보기만 할 거면 생략

### 휴대폰에서 매일 쓰기

| 하고 싶은 것 | 방법 |
|---|---|
| 오늘 할 일 보기 | 열면 바로 [오늘] — '다음 할 일' 카드, 시간순 목록, 빈 시간 |
| 이번 주·다른 주 보기 | [주차별] → ◀ ▶ 또는 위 숫자 띠 |

| 끝낸 일 표시 | 항목 옆 **✓** |
| 안 해도 되는 과제 | **✕** (계속 제외) |
| 수업 듣기·과제 제출 | **▶ 수업** / **Canvas** → 휴대폰 브라우저에서 열림 |

- 화면은 5분마다 새 데이터를 받는다. 머리글의 "데이터 ○○:○○ 기준" 이 PC 가 마지막으로 올린 시각
- 보고서 작성·내용정리·자료 열기·⏱ 는 PC 대시보드에서만 된다
- 비밀번호를 바꿨거나 틀렸다고 나오면: ⚙ → "비밀번호도 다시 입력" 확인

## 퀴즈 복습 (R11 — 퀴즈 앱은 고치지 않음)

1. 퀴즈 앱(https://rhombusbork.github.io/Pharmacy/) 첫 화면의 **[기록 내보내기]** → 다운로드 폴더에 `quizapp-backup-날짜.json`
2. 비서가 가장 새 파일을 자동으로 읽는다 (파일은 옮기지 않음)
3. 문제마다 간격 반복 — 틀리면 다음 날, 연속으로 맞힐수록 1·3·7·14·30일 뒤
4. 복습할 문제가 있는 덱마다 **🔁 퀴즈 복습: 덱 이름 (n문제, 틀린 m)** 이 계획에 들어간다 → [▶ 퀴즈 풀기]
5. 다시 풀고 내보내면 그 복습은 자동 완료

- 지금 퀴즈 앱에 없는 덱(예: 중간고사 덱)은 복습을 만들지 않는다
- 기록이 14일보다 오래됐으면 복습을 만들지 않고, 아침 브리핑에서 "기록 내보내기"를 부탁한다
- 퀴즈 기록은 브라우저마다 따로 저장되므로, 휴대폰에서 푼 기록은 그 휴대폰에서 내보내야 한다

## 계획이 똑똑해지는 부분 (R5)

- ⏱ 기록이 같은 종류·과목에서 3번 쌓이면 예상 시간을 자동 보정 (통계 → 예상 시간 보정)
- 이미 ⏱ 로 한 시간은 남은 시간에서 뺀다
- 2시간 넘는 과제·할 일은 90분 이하로 나눠 여러 날에 (`split_over`, `chunk_minutes`)
- 블록마다 "왜 여기?" 이유, 머리글에 "이번 주 여유/부족"

## inbox.md 문법

```markdown
## 할 일
- [ ] 리바이어던 발표자료 제출 @11-20 ~2h        마감 11/20 23:59, 예상 2시간
- [ ] 린스타트업 발표 @11-13 18:00 ~90m #창업     마감 시각, 과목
- [ ] 생화학 공부 ~1h 매주:화,목                  매주 그 요일 안에
- [ ] 논문 읽기                                    기한 없음 (장기 할 일)
- [x] 린스타트업 텍스트 제출 @11-11                체크 = 완료, 체크 풀면 다시 열림

## 완료
- m2890903                    키(TODAY.md 의 `...`)나 제목 단어 — 한 번 처리되면 지워도 완료 유지

## 제외
- 생약학 조별학습활동          여기 있는 동안 계속 제외 — 지우면 다시 나타남
```

- 반복 할 일 하나를 완료하려면 `## 완료` 에 날짜 붙은 키를 적는다: `i:생화학 공부@11-12`
- Canvas 과제·퀴즈는 **제출하면 자동으로 완료**된다 (조장 대표 제출 포함).
  강의는 LearningX 가 연결돼 있으면 **다 들으면 자동 완료**, 로그인이 만료됐을 때는 [✓ 들었음] 또는 `## 완료` 에 키.
- `## 제외` 에 제목 단어를 쓰면 같은 이름의 과제가 앞으로 생겨도 계속 제외된다. 그중 하나만 살리려면 `!키` 줄을 더한다
  (대시보드의 "단어 규칙으로 숨김" 알림의 [보이기] 가 이 줄을 적는다)

## 명령 (`bin/pa`)

| 명령 | 하는 일 |
|---|---|
| `bin/pa watch` | 자동 감시 + 대시보드 서버 http://localhost:8765 (VSCode 를 열면 자동 실행됨) |
| `bin/pa run [--full]` | 한 번 실행: inbox → (`--full` 이면 Canvas·공지·자료) → 계획 → 마감 캘린더 → TODAY.md·대시보드 |
| `bin/pa list` | 남은 할 일 (맨 앞이 키) |
| `bin/pa task <키>` | 한 항목: 마감·주소·Canvas 과제 설명·보고서 파일 이름·연결된 자료 |
| `bin/pa links [키]` / `link <키> <파일>…` / `unlink <키> <파일>…` | 연결된 자료 보기·연결·빼기 |
| `bin/pa notices [--all]` | 읽지 않은 공지 (`--all` 최근 2주 전부) |
| `bin/pa done/ignore/unignore <키>` | 완료 / 계속 제외 / 제외 취소 |
| `bin/pa time <키> <분>` | 예상 소요 시간 조정 |
| `bin/pa plan [--dry-run]` | 계획만 다시 |
| `bin/pa lectures [과목] [--open N]` | 이번 주 강의 목록·열기 |
| `bin/pa browser login` | 학교 로그인 저장 (LearningX 연결) — 사용자가 직접 할 때만 |
| `bin/pa google-login` | Google Calendar 다시 로그인 (Windows 브라우저가 열림) |

VSCode 에서 `Ctrl+Shift+P → 작업 실행 → 비서: 지금 전체 동기화` 로도 실행할 수 있다.

## 계획 규칙 (`config/timetable.yaml` 의 `planner`)

- 마감이 가까운 순으로, 월·수·금·토 빈 시간에 먼저 배치하고 부족하면 일요일, 그래도 없으면 나머지 요일
- 대면 수업·약속(Google Calendar) 시간은 피함, 하루 최대 `max_minutes_per_day`
- 같은 과목의 퀴즈·과제는 그 과목 강의 뒤, 이미 시작한 블록은 고정

## 엔진이 알아서 하는 것 (가볍게)

- 바뀐 게 있을 때만 계획을 다시 짜고(할 일·설정·⏱ 기록이 바뀌었거나, 1시간 지났거나, 계획 블록이 지나갔을 때),
  마감 캘린더도 마감이 바뀌었거나 6시간이 지났을 때만 Google 에 묻는다
- 단계마다 따로 실패한다 — Canvas 가 안 돼도 계획·화면은 갱신되고, 무엇이 안 됐는지 ⚠️ 로 알린다
- Google 로그인이 만료되면 엔진이 멈추지 않고 "Google Calendar 로그인 필요" + [Google 다시 로그인] 버튼
- `pa/*.py` 코드가 바뀌면 엔진이 새 코드로 스스로 다시 시작한다 (Claude 작업이 진행 중이면 끝난 뒤)
- 다운로드 폴더는 30초마다 맨 위만 한 번 본다. 그 목록을 📄 자료 창의 📥 가 그대로 쓴다
