# 자료 연결 기능 계획서 (추천 + 실시간 찾기 + 경로 Tab + 📁 둘러보기)

> 작성 2026-11-12 · 상태: **구현 완료 (2026-11-13, M1~M7)** — 사용법은 [usage.md "자료 연결"](usage.md)
> 계획과 달라진 점: ① 📄 는 연결된 자료가 하나면 열면서 **창도 함께** 보여 줌 (더 넣을 수 있게)
> ② 🧩 는 강의 줄의 작은 버튼 + 📄 창 아래 둘 다 ③ 경로 모드에서도 📥 를 켜면 `다운로드/` 로 들어갈 수 있음
> ④ 짝 후보가 여러 개면 추천 맨 앞에 "같은 주차 자료" 로 (Canvas 확인 때 기록, 추가 요청 없음)
> 원칙: **가볍게** (파일 이름만, 필요한 폴더만, 디스크는 최소로) · **프로그램만으로** (Claude 안 씀) ·
> **규칙이 바뀌는 판단은 대화로** (프로그램이 몰래 규칙을 바꾸거나 추측으로 확정하지 않음)

---

## 1. 목표

할 일마다 **"연결된 자료"** 를 두고, 📄 자료 · 🤖 내용정리 · ✍ 보고서 작성이 그 자료를 먼저 쓴다.
자료는 ① 자동 추천에서 고르거나 ② 이름 몇 글자로 찾거나 ③ 경로를 치며 Tab 으로 들어가거나 ④ 📁 로 눌러 다니며 연결한다.

## 2. 연결하는 폴더 (필요한 것만)

| 이름 | 위치 | 포함 | 파일 수(현재) |
|---|---|---|---|
| 자료 | `~/study_system/materials/` | pdf·ppt·pptx·doc·docx·hwp·hwpx·md·txt | 약 130 |
| 노트 | `~/study_system/notes/` | md | 약 20 |
| 보고서 | `~/report/` | md·pdf·docx·hwp | 약 5 |
| 다운로드 | Windows 다운로드 **맨 위만**, **최근 7일**, 문서 파일만 | — | 버튼을 눌렀을 때만 |

- 퀴즈 앱 파일은 **찾기 범위에 넣지 않는다** (결정). 퀴즈는 '만드는' 쪽으로만 연결한다 (8장).

- 합계 약 160개 (study_system + report). 이 범위는 `config/materials.yaml` 한 곳에 적는다. **범위를 바꾸는 건 대화로** 정하고 그 파일을 고친다.
- 그림(png·jpg)·스크린샷·`.git`·앱 코드(js·css)는 넣지 않는다.

## 3. 가볍게 만드는 방법

| 부분 | 방법 | 비용 |
|---|---|---|
| 파일 목록 | 엔진이 위 폴더의 **이름·날짜·크기만** 모아 메모리에 1분 보관 (`/api/files`) | 400개 기준 0.1초, 1분에 최대 1번 |
| 실시간 찾기 | 목록(약 30KB)을 화면이 **한 번** 받아 두고, 글자를 칠 때마다 **화면 안에서** 거른다 | 디스크·서버 0 |
| 경로 Tab | 같은 목록에서 폴더 단위로 묶어 보여 줌 | 0 |
| 📁 둘러보기 | 누른 폴더 **하나의 목록만** 받아 옴 (`/api/ls`) | 클릭당 1번 |
| 다운로드 | 엔진의 기존 감시가 기억한 "최근 받은 파일"을 그대로 보여 줌 → 자료 창 때문에 Windows 쪽을 여는 일 **0번**. 감시 주기 5초 → 30초 | 지금의 1/6 |
| 짝 연결 | 강의 플랫폼에서 자료를 **받을 때 이미 읽은 정보**로 기록 (추가 요청 없음) | 0 |
| 파일 내용 | 연결·찾기에서는 **읽지 않음**. 내용정리·보고서를 누를 때만 그 파일 | — |

새 라이브러리 없음. 저장은 DB 표 하나 (`links`).

## 4. 설계

### 4-1. 데이터 (`data/pa.db`)
```
links (key, path, origin, created_at)   -- origin: user(직접) | pair(강의 플랫폼 짝) | removed(짝을 사용자가 뺌)
```
- 할 일 하나에 **파일을 하나씩, 원하는 만큼** 추가한다 (폴더째 연결은 하지 않음 — 결정).
  1개 넣으면 1개, 2개 더 넣으면 3개를 참고한다. 최대 개수는 `config/materials.yaml` 의 `max_links` (기본 10, 대화로 변경).
- **직접 고른 것(user)이 항상 우선**, 짝(pair)은 기본값.
- 자동 추측(제목 번호 매칭)은 저장하지 않고 **추천에만** 보여 준다 → 사용자가 누르면 user 로 저장.

### 4-2. 추천 순서 (아무것도 안 쳤을 때)
1. 이미 연결된 자료 (칩으로 위에 표시)
2. 강의 플랫폼 짝 (17강 ↔ 17강_배포용)
3. 제목 번호가 맞는 자료·노트 (Ch22 ↔ Ch22…)
4. 그 과목 폴더의 최근 파일 3개

### 4-3. 실시간 찾기 규칙
- 띄어쓰기로 나눈 **모든 단어가 경로에 들어간 것**만 (순서·대소문자 무관)
- 점수: 파일 이름에서 맞음 > 경로에서만 맞음 · 단어 앞부분에서 맞음 가산 · 그 과제의 과목 폴더 가산 · 최근 파일 가산
- 위 8개 표시, 맞은 글자 굵게, "외 n개 더 보기"
- 키: `↑↓` 고르기 · `Tab` 입력칸 채우기 · `Enter` 연결 · `Esc` 닫기

### 4-4. 경로 Tab
- 입력에 `/` 가 있으면 **폴더 모드**: 그 폴더 바로 아래의 폴더·파일만 보여 줌
- `Tab` = 고른 항목으로 채우기 (폴더면 끝에 `/` 붙여 한 단계 들어감), 여러 개가 같은 앞부분이면 공통 부분까지 채우기
- 폴더에서 `Enter` = 그 폴더로 들어가기 (연결은 파일만)

### 4-5. 📁 둘러보기
- 그 과제의 **과목 자료 폴더에서 시작**. 위에 [자료] [노트] [보고서] [퀴즈] [📥 다운로드] 바로가기
- 경로 표시줄(누르면 그 단계로), ⬆, "이 폴더에서 거르기" 칸, [이름순/최근순]
- 폴더 줄: 누르면 들어감 / 파일 줄: ☐ 체크 · [열어보기]
- 아래 [선택한 n개 연결]

### 4-6. 연결된 자료를 쓰는 곳
| 버튼 | 바뀌는 점 |
|---|---|
| 📄 자료 | 연결된 게 1개면 바로 열기, 여러 개면 칩 목록 |
| 🤖 내용정리 | 연결된 PDF 가 있으면 그것 (여러 개면 고르기) |
| ✍ 보고서 작성 | **연결한 파일 전부**를 참고로 (최대 `max_links`). 연결이 없으면 지금처럼 자동 추측 |
| 휴대폰 | 연결된 자료 **이름만** 표시 (파일은 PC 에 있음) |

## 5. 규칙이 바뀔 수 있는 부분 — 프로그램이 정하지 않고 대화로

**지금 정할 것** (아래 "결정 사항")과, **쓰다가 생기는 경우** 를 나눈다.

### 쓰다가 생기는 경우: 프로그램은 '확인 필요'로 보여 주고 멈춘다
| 상황 | 프로그램이 하는 일 | 하지 않는 일 |
|---|---|---|
| 연결한 파일이 옮겨지거나 지워짐 | 칩에 ⚠️ "파일 없음" + [다시 찾기] (같은 이름 후보를 추천) | 다른 파일로 몰래 바꿔 연결 |
| 짝 후보가 2개 이상 (같은 주차에 자료가 여러 개) | 추천에 모두 보여 주고 연결은 하지 않음 | 하나를 골라 확정 |
| 짝 자료와 직접 고른 자료가 다름 | 직접 고른 것만 씀, 짝은 추천으로만 | 짝으로 덮어쓰기 |
| 다운로드 파일을 연결 | 기본은 **과목 폴더로 옮겨서 연결** (결정). 과목을 모르면 과목을 물음 | 과목을 추측해서 몰래 옮기기 |
| 연결 개수가 `max_links` 를 넘음 | "최대 n개" 안내, 더 넣으려면 채팅에서 변경 요청 | 오래된 것을 몰래 빼기 |
| 연결 범위 밖의 파일을 원함 | "범위 밖" 안내 + "채팅에서 범위 추가를 요청하세요" | 범위를 스스로 넓히기 |

### 설정 파일 원칙
- 범위·순서·기간 같은 규칙은 `config/materials.yaml` 에만. 프로그램은 읽기만 하고 **고치지 않는다**.
- 바꾸고 싶으면 채팅에서 말하면 Claude 가 이 파일을 고친다 (규칙 변경 = 대화).

## 6. 작업 단계

| 단계 | 내용 | 확인 방법 |
|---|---|---|
| M1 | `config/materials.yaml`, `links` 표, 파일 목록 모으기(`/api/files`, 1분 보관), 폴더 목록(`/api/ls`, 범위 밖 거부) | 단위 테스트, 범위 밖 경로 거부 |
| M2 | 짝 연결: 강의 플랫폼 자료를 받을 때 같은 주차의 강의와 짝 기록 (이미 받은 자료는 다음 동기화 때 채움) | 17강·윤리 강의로 확인 |
| M3 | 자료 창: 칩 + 추천 + 실시간 찾기 + 경로 Tab + 키보드 | 브라우저 시험 (입력→후보→Tab→Enter) |
| M4 | 📁 둘러보기 (바로가기, 경로, 체크, 열어보기) | 브라우저 시험 |
| M5 | 다운로드: 감시 결과 재활용, 최근 N일, 30초 주기, 옮겨서 연결 | 시험 파일로 확인 후 삭제 |
| M6 | 📄·🤖·✍ 가 연결된 자료를 먼저 쓰도록, ⚠️ 파일 없음 처리, 휴대폰에 이름 표시, 문서 | 전체 테스트 + 화면 확인 |
| M7 | 퀴즈 만들기 연결: `/quiz` 스킬이 연결된 자료를 재료로 쓰도록, 대시보드 [🧩 퀴즈 요청 복사] | 복사 문장 확인 |

예상: 2시간 안팎. 각 단계마다 테스트·커밋·백업.

## 7. 결정 사항 (2026-11-12 확정)

1. 퀴즈 앱 파일은 찾기 범위에 넣지 않는다
2. 다운로드 파일은 **과목 폴더로 옮겨서 연결**
3. 다운로드는 **최근 7일**
4. 자료는 **파일 하나씩 원하는 만큼** (폴더째 연결 없음), 최대 `max_links` = 10 (대화로 변경)

## 8. 퀴즈 만들기 (study_system 자료 → 퀴즈 앱)

- 퀴즈 제작은 **문제를 고르는 판단이 필요해서 대화로** 한다 (퀴즈 프로젝트 규칙: 계획서 → 사용자 승인 → 제작).
- 이 채팅에서 "17강 자료로 퀴즈 만들어줘" → `/quiz` 스킬이 퀴즈 프로젝트의 CLAUDE.md·계획 방법을 읽고,
  **그 할 일에 연결된 자료**(없으면 study_system 의 해당 자료·노트)를 재료로 계획서를 만들어 승인을 받은 뒤
  `~/quiz_system_project/pharmacy/decks/` 에 덱을 만들고 그 프로젝트의 브랜치·커밋 규칙대로 반영한다.
- 대시보드에는 버튼 대신 각 강의 옆 **[🧩 퀴즈 요청 복사]** 를 둔다: 누르면 "○○ 자료(연결된 파일 목록)로 퀴즈 만들어줘"
  문장이 복사되어 채팅에 붙여 넣기만 하면 된다 (Claude 는 채팅에서만, 엔진은 Claude 안 씀).
- M7 단계로 추가: 스킬 문서 갱신 + 복사 버튼.
