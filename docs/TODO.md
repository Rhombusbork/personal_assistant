## 1. 사용자가 해야 할 것

| 급함 | 할 일 | 왜 | 방법 |
|---|---|---|---|
| 11/18 전 | Google OAuth 앱을 **프로덕션**으로 (지금 '테스트'라면) | 테스트 상태의 앱은 Google 로그인이 **7일마다 만료**된다 → 학습 계획·마감 캘린더·휴대폰 알림이 멈춤 | Google Cloud Console → API 및 서비스 → OAuth 동의 화면 → **앱 게시**(프로덕션으로 푸시). 그다음 대시보드 [Google 다시 로그인] 또는 `bin/pa google-login` 한 번. "확인되지 않은 앱" 경고가 나오면 고급 → 계속 |
| 편할 때 | LearningX **다시 로그인** | 11/12 부터 만료(400). 그동안 자료 자동 다운로드·수강 완료 자동 체크·정확한 출석 마감이 멈춤 (약학윤리 자료 등) | 대시보드 ⚠️ 줄의 [다시 로그인]. 그 뒤 평소 브라우저에서 강의가 안 열리면 Canvas 로그아웃 → 다시 로그인 |
| 확인 | 휴대폰 입력 1건 반영 못 함 (11/12 17:30 "저녁밥") | 그때 휴대폰이 비밀번호 없이 잠가 PC 가 못 풂 (고쳤음) | 아직 필요하면 다시 입력 → 경고의 [확인] |
| 시험 공지 뒤 | 기말고사 날짜 | 시험 모드(7·4·2일 전 복습)는 날짜가 있어야 켜진다 | 📝 시험 일정 후보의 [할 일로 추가], 또는 채팅에 "생화학 기말 12/15 10시" |
| 가끔 | 퀴즈 앱 [기록 내보내기] | 틀린 문제 복습 일정의 재료. 14일 넘게 안 하면 복습을 만들지 않음 | 퀴즈 앱 첫 화면 버튼 → 다운로드 폴더에 저장되면 자동으로 읽음 |
| 선택 | VSCode 자동 작업 허용 | 창을 열 때 엔진·대시보드가 자동으로 켜지게 (Claude 는 사용자 설정을 못 바꿈) | `Ctrl+Shift+P → Tasks: Manage Automatic Tasks → Allow Automatic Tasks` |
| 선택 | Windows 작업 스케줄러 | VSCode 를 안 열어도 하루 3번 동기화·휴대폰 화면 갱신 | usage.md "VSCode 를 안 열어도 자동 실행" 의 PowerShell 한 줄 |
| 선택 | 채팅에서 `bin/pa` 허용 | 매번 실행 허락을 묻지 않게 | 채팅에서 `/permissions` → `Bash(bin/pa:*)` 허용 |

지금 엔진은 VSCode 와 별도로 켜져 있다 (기록: `data/engine.out`). 코드가 바뀌면 스스로 다시 시작한다.
VSCode 를 다시 열면 "이미 다른 창에서 감시 중" 이라고 나오는데 정상이다.

## 2. 막힐 수밖에 없는 부분 (프로그램·Claude 가 못 하는 것)

| 무엇 | 왜 막힘 | 대신 |
|---|---|---|
| Google 앱 게시 설정 | 사용자 Google 계정의 콘솔 화면에서만 가능 | 1장 방법 |
| 학교(LearningX) 다시 로그인 | 규칙상 비서가 스스로 로그인하지 않음 + 학교가 로그인을 하나만 유지해 평소 브라우저가 끊길 수 있음 | 사용자가 원할 때 버튼 |
| 강의 페이지 열람·출석 | 열람·출석 기록이 남으므로 하지 않음 (원칙) | 데이터 API 만 읽음 |
| VSCode 사용자 설정·Claude 권한 파일 변경 | 안전 장치가 Claude 의 수정을 막음 (정상) | 사용자가 직접 (1장) |
| 화면 확인 | VSCode 탭·휴대폰 화면은 Claude 가 직접 볼 수 없음. 브라우저 자동 시험(headless)으로만 확인 | 쓰다가 이상하면 채팅에 알려 주기 |
| 보고서 초안 실제 실행 | 구독 사용량을 쓰고, 어떤 과제로 할지는 사용자가 정할 일 | ✍ 를 한 번 눌러 보기 |
| 퀴즈 만들기 자동화 | 무엇을 문제로 낼지는 판단 → 퀴즈 프로젝트 규칙상 계획서 승인이 필요 | 🧩 복사 → 채팅 |
