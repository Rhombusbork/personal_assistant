description: 오늘/이번 주 브리핑과 학습 계획. "오늘 뭐 해", "일정", "계획 짜줘", "할 일", "마감" 같은 요청에 사용.
---

1. `.venv/bin/python -m pa.sync_canvas` 로 과제 마감을 최신화한다.
2. `.venv/bin/python -m pa.plan --dry-run` 으로 계획을 확인한다.
3. 아래 형식으로 짧게 보고한다.
   - 📅 오늘: 대면 수업과 계획된 학습 항목 (시간순)
   - ⏰ 3일 안 마감
   - ⚠️ 마감 전 시간이 부족한 항목 (있으면)
4. 사용자가 "좋아", "반영해" 하면 `pa.plan` 을 실제로 실행해 캘린더에 넣는다.
5. 사용자가 어떤 과제를 안 해도 된다고 하면 (조장만 제출 등) `pa.tasks ignore <키>`,
   강의를 들었다고 하면 `pa.tasks done <키>` 로 기록하고 다시 계획한다.
