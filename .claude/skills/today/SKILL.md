2. `TODAY.md` 를 읽고 짧게 보고한다: 오늘 일정 / 3일 안 마감 / ⚠️ 확인 필요.
3. 할 일 추가·완료·제외 요청은 `inbox.md` 에 적고 (`## 할 일`, `## 완료`, `## 제외`) `bin/pa run` 을 실행한다.
   - 조장만 제출 등 → `## 제외` 에 키 또는 제목 단어
   - 강의를 들었다 → `## 완료` 에 키
