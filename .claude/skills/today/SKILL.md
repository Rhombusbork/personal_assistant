description: 오늘/이번 주 브리핑과 학습 계획, 할 일 추가·완료·제외, 시험 일정, 공지. "오늘 뭐 해", "일정", "계획 짜줘", "할 일", "마감", "시험", "공지" 같은 요청에 사용.

1. `TODAY.md` 의 "갱신" 시각을 본다. 1시간 넘게 지났으면 `bin/pa run` (Canvas 확인이 3시간 넘었으면 `bin/pa run --full`).
2. `TODAY.md` 를 읽고 짧게 보고한다: 오늘 일정 / 3일 안 마감 / ⚠️ 확인 필요.
   ⚠️ 줄(로그인 만료·동기화 실패·시간 부족·휴대폰 입력 실패)은 빼지 말고 함께 알린다. 추측으로 답하지 않는다.
3. 할 일을 바꿀 때는 `inbox.md` 를 고치고 `bin/pa run` (문법: docs/usage.md "inbox.md 문법"). 키는 `bin/pa list` 맨 앞.
   - 추가: `## 할 일` 에 `- [ ] 제목 @11-20 18:00 ~2h #과목` (날짜가 없으면 '하고 싶은 일')
     특정 때부터 하려면 `>11-15 09:00` 을 더한다 (그 전에는 계획에 넣지 않음)
   - 완료: `## 완료` 에 키 (반복 할 일은 `키@11-12`)
   - 제외: `## 제외` 에 키(이것만) 또는 제목 단어(같은 이름은 앞으로도). 단어 규칙에서 하나만 살리려면 `!키`
4. 시험 날짜를 들으면 `<과목> 기말고사 @12-15 10:00 #<과목>` 으로 넣는다 → 시험 7·4·2일 전 복습이 자동으로 잡힌다.
   공지에서 찾은 후보는 대시보드 📝 시험 일정 후보에 있다 (확정은 사용자가 [할 일로 추가]).
5. 공지를 물으면 `bin/pa notices` (최근 2주 전부는 `--all`). 요약·제외 후보는 대시보드 [🤖 요약·제외 후보 찾기].
   제외는 사용자가 정한다.
6. 한 할 일의 자세한 정보(마감·Canvas 설명·보고서 파일·연결된 자료)는 `bin/pa task <키>`.
7. 계획 방식이 마음에 안 든다고 하면 규칙을 바로 바꾸지 말고 `rules` 스킬로 (무엇을 어떻게 바꿀지 확인한 뒤).
