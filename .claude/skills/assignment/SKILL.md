---
name: assignment
description: Canvas 과제(보고서, 배움노트, 결과보고서, 발표자료 등)를 시작하거나 초안을 쓰고 다듬을 때 사용. "과제 하자", "보고서 써줘", "초안 고쳐줘", "배움노트" 등.
---

1. `bin/pa task <키>` 로 마감·Canvas 과제 설명(배점·제출 형식·허용 파일)·보고서 파일 이름·연결된 자료를 한 번에 본다.
   키는 `bin/pa list` 맨 앞.
2. **`~/report/CLAUDE.md` 를 읽고** 글쓰기·파일명 규칙을 따른다.
3. 참고 자료
   - 연결된 자료가 있으면 **그것만** 쓴다 (사용자가 📄 자료 창에서 고른 것).
   - 없으면 `~/study_system/materials/<과목>/` 의 맞는 자료 + `~/study_system/notes/<과목>/` 의 사용자 노트.
     어떤 자료를 쓸지 짧게 말하고, 필요하면 `bin/pa link <키> <파일>` 로 연결해 둔다 (다음에도 같은 자료).
   - 사용자의 노트에 있는 사용자 자신의 표현과 생각을 우선 활용한다.
4. 대시보드 **✍ 보고서 작성** 창의 [💬 채팅에서 같이 쓰기] 로 오면 요청에 키·보고서 파일·사용자의 지침·참고 자료가 들어 있다
   (파일은 VSCode 에 열려 있음). 그 지침과 자료를 따르고, 먼저 구성을 제안해 확인받은 뒤 한 부분씩 쓴다.
   지침은 `bin/pa task <키>` 에도 나온다.
   대시보드에서 [🤖 초안 한 번에] 로 이미 초안이 있을 수도 있다 (`bin/pa task` 의 '보고서 파일').
   - 있으면 그 파일을 고쳐 나간다. 처음부터 다시 쓰려면 대시보드 ✍ 창의 [🤖 초안 한 번에] (지금 파일은 `_old1` 로 보관).
   - 초안의 `[✍ 내 생각: …]` 자리는 사용자가 채울 곳이다. 지어서 채우지 말고, 사용자가 말해 주면 그 말을 살려 넣는다.
5. 채팅에서 처음부터 쓸 때도 같은 파일 이름·규칙. 확인하지 않은 사실·참고문헌은 쓰지 않는다.
6. 보고서 파일을 만들거나 다 쓰면 **Windows 탐색기로 그 파일 위치를 열어 준다** (사용자 요청 — 제출할 때 끌어다 놓기):
   `bin/pa reveal <파일>`. PDF 로 내야 하면 (허용 파일: pdf) `bin/pa pdf <보고서.md>` — 같은 폴더에 A4 PDF,
   쪽수를 알려 주고 탐색기에서 PDF 를 선택해 보여 준다. "한 장" 과제면 1쪽인지 확인한다.
   대시보드 ✍ 창의 [📄 PDF 만들기]·[📂 위치] 도 같다.
7. 제출은 사용자가 직접 한다. Canvas 과제는 제출하면 다음 Canvas 확인 때 자동 완료된다.
