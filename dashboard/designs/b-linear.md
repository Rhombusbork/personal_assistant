# 시안 B — "조용한 파워 툴" (Linear · Superhuman · Height 계열)

한 줄 개념: **화면에는 제목과 날짜만, 버튼은 고를 때만 나타난다.** 나머지는 키보드와 명령 팔레트로 한다.

보기: http://localhost:8765/designs/b-linear.html (보기 전용. GET /api/data 만 읽고, 버튼을 누르면 "시안: 실제 동작은 하지 않음" 알림만 뜸)

## 쓴 기법 (어디에 보이는지)

- **명령 팔레트** (Ctrl+K · `/`): 모든 보기·할 일·확인할 것·시스템 명령을 한 곳에서 찾는다. 퍼지 찾기라 "결보"만 쳐도
  "11주차 **결**과**보**고서"가 나온다. 고른 줄이 있으면 그 할 일의 작업이 맨 위에 뜨고, 찾는 글자를 그대로 "할 일로 추가"할 수도 있다.
- **키보드 우선**: `J/K` 이동, `Enter` 상세, `X` 완료, `S` 시작, `O` 열기, `R` 보고서, `M` 자료, `N` 내용정리, `Q` 퀴즈 요청,
  `V` VSCode, `E` 제외, `C` 새 할 일, `1–6` 보기 바꾸기, `←/→` 주 이동, `?` 단축키 표. 아래 띠에 지금 쓸 수 있는 키가 나온다.
- **점진적 공개(progressive disclosure)**: 줄에는 시간 · 종류 아이콘 · 제목 · 과목 · D-n 만. 마우스를 올리거나 J/K 로 고르면 오른쪽 메타 자리에
  작은 아이콘 버튼 3개(열기 · 시작 · 완료 · ⋯)가 바뀌어 나타난다. 7개 버튼 전부는 **오른쪽 상세 패널(peek)** 에서 단축키와 함께.
- **일정한 밀도**: 모든 목록 줄 32px(휴대폰 48px), 간격은 4pt 격자(4·8·12·16·24·32), 시간은 고정폭 숫자.
- **단색 + 강조색 하나**: 회색 계열 + 남보라 하나. 종류는 색 대신 **아이콘 모양**(▷ 강의, 문서 과제, ? 퀴즈, ↻ 복습, ○ 할 일).
  빨강은 '지남' 한 군데에만.
- **채운 카드 대신 1px 실선**: 섹션은 얇은 선과 작은 회색 머리글로만 나눈다(근접·정렬의 게슈탈트 원칙).
- **왼쪽 사이드바 + 본문**: 오늘 / 주차별 / 마감 / 확인할 것 N / 하고 싶은 일 / 통계. 숫자 배지는 '확인할 것'에만 강조색.
- **분류함(Inbox/triage)**: 처리해야 할 것만 한 보기에 모음. 줄마다 첫 버튼은 `Enter`, 무시·아니요는 `⌫`. 5개가 넘는 묶음은 3개만 보이고 "외 N개 더 보기".
- **휴대폰**: 사이드바 → 아래 탭 6개(확인 배지), 상세 패널 → 아래 시트, 가로 스크롤 없음(390px 에서 확인).
- **다크 모드**: 시스템 설정을 따르고, 팔레트에서 "테마: 어둡게/밝게"로 바꿀 수도 있음.

## 무엇이 어디로 옮겨졌나 (지금 대시보드 → 시안 B)

| 지금 | 시안 B |
|---|---|
| 맨 위 큰 초록 '오늘 브리핑' 카드 | '지금 할 일' 아래 **접힌 한 줄**(수업 0 · 계획 3개 · 이틀 안 마감 7 …) — 펼치기 / 오늘 시작 |
| 주황 경고 카드 | **확인할 것 > 알림** (확인 · 보이기 · 다시 로그인 버튼 그대로) |
| 빠른 입력 칸 + '자세히 입력' | `C` 또는 상단 [+ 새 할 일] 창 (자세히: 날짜·시간·예상·분류·반복), 팔레트에서도 바로 추가 |
| 상단 요약 알약 4개 | 상단 막대 오른쪽의 회색 숫자 한 줄 |
| 지금 할 일 카드 | 맨 위 한 줄 띠 (보고서·시작·완료·⋯ 만 보임), 타이머도 같은 자리 |
| 줄마다 버튼 6–7개 | 줄 위에 올리면 3개, 전부는 상세 패널 · 팔레트 · 단축키 |
| ✍ 보고서 / 📄 자료 창 (화면 위에 끼어듦) | 오른쪽 상세 패널 안에서 열리는 것으로 가정 (위쪽을 밀어내지 않음) |
| 오른쪽 '다가오는 마감'(2주) | **마감** 보기 (날짜별 묶음, 지난 마감 포함). 오늘 보기에는 '곧 마감 3일' 최대 6줄만 |
| 새 점수 · 시험 후보 · 새 공지 · 제외 후보 · 작업 | **확인할 것** 의 각 묶음 |
| 📥 새로 받은 파일 11개 | **확인할 것 > 새로 받은 파일** (3개 + 더 보기, 과목 고르기 · 옮기기 · 무시) |
| 하고 싶은 일 카드 | **하고 싶은 일** 보기 (`T` = 오늘 빈 시간에 넣기) |
| 제외한 것 | **마감** 보기 맨 아래 접힌 '제외한 것' (취소) |
| 📊 통계(접힌 영역) | **통계** 보기: 숫자 타일 4개 + 학습량 · 완료 추이 · 과목별 진행 · 돌아보기 · 시간 기록 · 보정 · 퀴즈 |
| 동기화 · 실시간 표시 · 계획/Canvas 시각 | 사이드바 아래 |
| '퀴즈 기록 오래됨' 안내 | 브리핑 한 줄 + 확인할 것 > 퀴즈 복습 |

## 약점 · 대가 (솔직하게)

- **배우는 데 시간이 든다.** 단축키와 팔레트를 안 쓰면 버튼이 숨어 있어 오히려 한 번 더 눌러야 한다(⋯ → 상세).
- **눈에 덜 띈다.** 색을 뺐기 때문에 과목·종류를 색으로 한눈에 구분하던 맛이 줄었다. 아이콘 모양 구분은 익숙해져야 보인다.
- **휴대폰은 마우스 올리기가 없다.** 줄을 누르면 아래 시트가 열리는 한 단계가 더 생긴다(분류함 버튼은 항상 보이게 함).
- 확인할 것이 **한 보기에 몰려** 있어, 그 탭을 안 열면 경고를 놓칠 수 있다 → 사이드바·탭 배지(숫자)로만 알린다.
- 주간 캘린더는 휴대폰에서 칸 안 가로 스크롤(페이지 자체는 가로 스크롤 없음).
- 시안이라 보고서·자료 창은 실제로 만들지 않았다(상세 패널 안에서 열린다는 가정만).
