# 시안 A-1 — 사용성 평가로 다듬은 A

**한 줄 개념**: A의 차분한 한 단 화면은 그대로 두고, 평가에서 나온 문제만 고쳤다. 상태가 보이고, 손가락으로도 닿고, 실수해도 되돌릴 수 있고, 급한 것은 눈에 먼저 들어온다.

## 2. 방법 → 바뀐 것
- **닐슨 휴리스틱 평가**: 위 표의 심각도 2 이상을 모두 고쳤다. 확인 창은 "되돌릴 수 없는 것"(삭제, 규칙이 남는 '앞으로도')에만 쓰고, 나머지는 되돌리기로 — 확인 창 남발은 습관적 클릭을 부른다 (NN/g).
- **피츠의 법칙 · 터치 크기 (Apple HIG 44pt, WCAG 2.2 2.5.8 24px·2.5.5 44px)**: 체크 원은 음수 여백으로 44×44 영역을 겹쳐 줄 높이는 그대로. 주 버튼 44px, ⋯ 36px(마우스)/44px(터치), 탭·링크 32px 이상. 폰에서 24px 미만 버튼 0개(자동 측정). 위험 버튼(삭제)은 확인 창 오른쪽 끝, 기본 포커스는 반대쪽 '취소'.
- **WCAG 2.2 AA**: 대비 표(3절), 3px 포커스 링(줄 전체에도), 아이콘 버튼 aria-label, ⋯ 에 aria-haspopup/expanded, 메뉴 ↑↓·Home·End, 시트 안에 포커스 가두기·닫으면 원래 버튼으로, progressbar·timer 역할, 색 외에 글자("지남", 종류 이름)로도 뜻 전달(1.4.1).
- **전주의 속성 · 의미 색**: 색 역할을 나눴다 — 파랑=누를 것·지금, 빨강=지남·긴급, 주황(#b45309)=주의, 종류 색=원 테두리만. 지난 마감은 "빨간 원 + 빨간 굵은 날짜" 두 속성이 겹쳐 훑기만 해도 튄다. 24시간 안 마감은 굵게("N시간 남음"). 경고는 심각도 3단계: 2=빨간 줄(로그인·엔진), 1=주황 줄(작업 실패·휴대폰 입력 못 받음·엔진 응답 없음), 0=접힘. 숫자 배지는 파랑 대신 회색(파랑은 행동 색).
- **게슈탈트 · DRY**: 한 대상은 한 화면에 한 번만 "온전히" 그린다. 주인공=전체 정보·행동, 타임라인=같은 자리에 얇은 "지금 ↑ 제목" 줄(연속성 유지, 행동 없음), 마감 목록=빼고 머리에 "(1개는 위 '지금')". 오늘 계획된 마감 줄에는 파란 "오늘 16:41 계획" 꼬리표(유사성으로 타임라인과 연결). 주인공 안의 "✓ 완료" 버튼도 원과 겹쳐 빼고 ⏱ 시간 재기를 꺼냈다. 위로 꺼낸 경고는 접힌 목록에서 다시 쓰지 않는다.

## 4. A → A-1 바뀐 것
- 머리: 날짜 줄 → 상태 줄 (엔진·갱신·Canvas·작업 스피너·⏱). 요약 맨 앞에 빨간 "마감 지남 N".
- "확인할 것" 위에 긴급 줄 (지금 데이터: LearningX 로그인 만료=빨강, 휴대폰 입력 1건=주황). 배지 15→13, 회색.
- 주인공: ✓ 완료 버튼 → ⏱ 시간 재기 (완료는 44px 원). 타이머 시:분:초.
- 타임라인: 주인공 블록은 "지금 ↑" 한 줄. 지난 줄은 투명도 대신 text3.
- 마감: 주인공 일 제외, 지난 마감 빨간 원, 24시간 안 굵게, "오늘 HH:MM 계획" 꼬리표.
- 줄: 주 행동 항상 보임(회색→파랑), 폰은 "작성/듣기/풀기/시작" 44px + 줄 누르면 행동 시트.
- 확인 창(삭제·앞으로도 제외), 되돌리기 토스트, 단축키 시트, 포커스 관리, 움직임 줄이기.
- 색: 강의 파랑→청록, 할 일 초록→회색, 파랑은 강조 전용.

## 5. 남은 약점
- 줄마다 회색 주 행동이 보여 A보다 오른쪽이 조금 붐빈다 (인식을 위해 고요함을 조금 냈다).
- text2·text3 차이가 작아져(7.5 vs 5.1) 위계가 색보다 크기에 더 기댄다.
- 체크 원의 44px 영역이 제목 왼쪽 10px 와 겹친다 — 잘못 누름은 되돌리기로만 막는다.
- 주차별 막대 띠는 여전히 옅다 (비텍스트 3:1 미만, 숫자 글자로 보완). 시간 격자도 아직 없다.
- 터치에서 줄을 누르면 시트가 뜨므로, 제목을 눌러 "선택만" 하는 동작은 없다.
- 긴급 줄은 매 30초 다시 그려도 화면 낭독기에 다시 읽히지 않게 live 영역을 빼 두었다 → 새로 생긴 경고는 직접 봐야 안다.
