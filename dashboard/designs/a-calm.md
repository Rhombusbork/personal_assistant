# 시안 A — 차분한 집중 (Calm focus)

**한 줄 개념**: 화면을 열면 "지금 할 일" 하나만 크게 보이고, 나머지는 글자 크기·회색 단계로 물러나거나 접혀 있다. (Things 3 · Apple 미리 알림 · Apple HIG 계열)

보기: http://localhost:8765/designs/a-calm.html · 지금 비어 있는 점수·시험·공지·작업 칸까지 보려면 `?sample=1`
보기 전용 시안이다. `GET /api/data` 만 읽고, 버튼을 누르면 "시안: 실제 동작은 하지 않음" 토스트만 뜬다.

## 적용한 기법과 화면에서 보이는 곳
- **점진적 공개 (progressive disclosure)**: 알림·점수·시험·공지·작업·새 파일·브리핑을 "확인할 것 N" 한 줄로 접었다. 줄마다 쓰던 버튼은 ⋯ 메뉴로, 보고서·자료 창은 화면을 밀어내지 않고 위에 뜨는 시트로 옮겼다.
- **화면당·줄당 주 행동 하나**: 화면 전체에서 파란 채움 버튼은 "지금 할 일"의 주 행동 하나뿐이다. 줄에서는 주 행동이 마우스를 올렸을 때만 글자 버튼으로 나타난다.
- **상자 대신 글자 위계**: 카드 테두리·배경을 없앴다. 제목 32 → 섹션 20 → 줄 15 → 보조 13 → 흐린 12 순서로 크기·굵기·회색 3단계(text/text2/text3)만으로 구분한다.
- **8pt 간격 체계**: 간격은 8·16·24·32·40·48 만 쓴다. 섹션 사이 40, 줄 안쪽 8.
- **색은 의미에만**: 종류 색은 원형 체크의 테두리에만 쓴다(강의 파랑, 과제 주황 …). 강조색 파랑은 "지금"과 주 행동, 빨강은 "지남"에만 쓴다. 이모지는 거의 뺐다.
- **힉의 법칙 (선택지 줄이기)**: 한 줄에 보이는 선택지가 7개에서 2개(○ 체크 + ⋯)로 줄었다. 메뉴 안의 항목은 열기·작성 / 자료·도구 / 기록 / 제외 네 묶음으로 나눴다.
- **밀러의 법칙·묶기 (chunking)**: 마감은 기본으로 앞으로 3일만, 날짜별(오늘·내일·모레)로 묶었다. 2주는 "2주 보기 (+11)"로 펼친다. 새 파일은 3개만 보이고 "8개 더 보기"로 나머지를 연다.
- **F자형 읽기**: 왼쪽 세로줄을 시간 → 체크 → 제목 순으로 맞췄다. 행동 버튼은 오른쪽 끝에 몰았다.
- **한 단, 최대 720px**: 오른쪽 열을 없앴다. 휴대폰에서도 순서가 같다(375px에서 가로 스크롤 없음). 다크 모드는 prefers-color-scheme 를 따른다.

## 무엇이 어디로 옮겨졌나 (지금 대시보드 → 시안 A)
| 지금 | 시안 A |
|---|---|
| 머리의 알약(pill) 4개 | 제목 아래 회색 글자 한 줄 (모자라면 빨강 "부족") |
| 큰 입력 카드 | 밑줄 하나짜리 "+ 새 할 일" 입력, "자세히"로 펼쳐 날짜·반복 입력 |
| 초록 아침 브리핑 카드 · 주황 경고 카드 | "확인할 것 N" 안의 "오늘 브리핑"과 "알림" 묶음 |
| 오른쪽 점수·시험·공지·작업·새로 받은 파일 카드 | 모두 "확인할 것" 안으로 (새 파일은 3개 + 더 보기) |
| 지금 할 일 카드 (버튼 7개) | 주인공 영역: 제목 24px, 진행 막대, 주 버튼 1 + ✓ 완료 + ⋯ |
| 타임라인 줄 버튼 7개 | 주 버튼 1(마우스를 올렸을 때) + ○(완료) + ⋯ (Canvas·자료·내용정리·🗂·🧩·⏱·제외) |
| 다가오는 마감 2주 (오른쪽) | 본문의 "다가오는 마감" 3일 + "2주 보기" |
| 제외 ✕ → 줄 안에서 바뀌는 버튼 | ⋯ → 제외… → 이것만 / 앞으로도 / 취소 (메뉴 안) |
| ✍ 보고서 창 · 📄 자료 창 (본문을 밀어냄) | 화면 위에 뜨는 시트 (폰에서는 아래에서 올라옴) |
| ⏱ 타이머 띠 | 기록 중이면 주인공 영역이 큰 경과 시간 + "끝내고 완료"로 바뀜 |
| 하고 싶은 일 · 제외한 것 · 📊 통계 | 맨 아래에 접힌 줄 3개 |
| 주차별 시간 격자 캘린더 | 학기 막대 띠(주별 남은 일의 양, 시험은 빨간 점) + 날짜별 목록 + 이 주에 마감 |

없앤 기능은 없다. 단축키 `/`·Ctrl+K·t·w·←→ 도 그대로 둔다.

## 약점 · 대가 (솔직하게)
- **숨긴 만큼 한 번 더 눌러야 한다**: 자료·🧩·🗂 처럼 자주 쓰던 버튼이 ⋯ 안으로 들어갔다. 손에 익은 사용자에게는 클릭이 1번 늘어난다.
- **"확인할 것"을 안 열면 놓친다**: 로그인 만료 같은 경고도 접혀 있다. 그래서 숫자 배지를 파랗게 해 두었지만, 한 줄이라 지나치기 쉽다.
- **주차별 보기가 단순해졌다**: 시간 격자가 없어서 빈 시간이 어디인지 한눈에 보이지 않는다. 블록을 눌러 고르는 기능도 빠졌다.
- **휴대폰은 마우스 올리기가 없다**: 줄의 주 행동은 ⋯ 안에서만 보인다. 대신 위의 "지금 할 일"에 크게 있다.
- **같은 일이 여러 번 나온다**: 지금 할 일이 주인공 영역·타임라인·마감 목록에 세 번 보인다. 화면이 넓어 보이는 대신 세로로 길어진다.
- **색을 줄였더니 종류 구분이 약하다**: 종류를 원형 체크 테두리 색으로만 알 수 있다. 강의(파랑)와 강조색(파랑)도 색이 겹친다.
