# 시안 C — 한눈 일정 (Glanceable agenda)

**한 줄 콘셉트**: 첫 화면에서 "지금 뭐 하지 · 다음은 · 뭐가 급하지"가 바로 보이고, 나머지는 눌러야 나온다.
Google 캘린더 일정 보기 · Sunsama 하루 계획 · Material Design 3 를 따름. 휴대폰(390px)을 먼저 만들고 PC 에서 넓힘.

보기: http://localhost:8765/designs/c-agenda.html (보기 전용 — `GET /api/data` 만 읽음, 버튼은 "시안: 실제 동작은 하지 않음" 안내만)

## 쓴 기법 (어디에 보이나)

- **모바일 우선 반응형**: 390px 한 줄 → 960px 넘으면 2단 (왼쪽 일정, 오른쪽 마감·하고 싶은 일 패널). 375px 에서 가로 스크롤 없음.
- **한눈에 보기(glanceability)**: 맨 위 "지금 / 다음 / 마감" 카드 3줄. 진행 중 블록은 남은 시간 + 진행 막대.
- **KPI 칩 3개가 유일한 요약**: 오늘 남은 계획 · 3일 안 마감(지남 수) · 이번 주 여유. 누르면 일정 / 마감 / 통계로 감.
- **일정(agenda) 먼저**: 시간 열 + 블록, 빨간 "지금" 선, 30분 넘는 빈 시간은 점선 칸. 지난 일정은 접어 둠.
- **Material 3 톤 표면**: 진한 색 카드 배경 없음. 표면 단계(s1~s3)로 구분하고, 과목 종류 색은 왼쪽 4px 띠와 점에만.
- **바텀 시트 / 사이드 시트**: 줄을 누르면 그 할 일의 모든 버튼이 시트에 (휴대폰은 아래에서, PC 는 오른쪽에서).
- **알림 벨 + 배지**: 확인할 것 전부(경고·새 점수·시험 후보·공지·제외 후보·작업·새로 받은 파일·브리핑)를 한 시트로.
- **FAB 빠른 추가**: 오른쪽 아래 + → 빠른 입력 시트 (`/` 키도). 예시 칩(@오늘 ~1h …)과 "자세히 입력" 접기.
- **44px 이상 터치 영역**: 체크 원·줄·칩·세그먼트 모두 44~60px.
- **D-day 묶음, 기본 3일만**: 지난 마감 → 오늘 → 내일 → D-2 → D-3. "2주 전체 보기"로 펼침.
- **세그먼트 버튼** 오늘 | 주차별. 주차별은 7일을 같은 일정 줄로 세로 나열 + 학기 주차 띠(가로 스크롤은 띠 안에서만).
- **다크 모드**: `prefers-color-scheme` 로 톤 표면 색을 바꿈. 아이콘은 이모지 대신 인라인 SVG.

## 약점 · 대가 (솔직히)

- **한 번 더 눌러야 함**: 자주 쓰던 ✍ 보고서·📄 자료가 줄에서 사라져 탭 2번. PC 에서 마우스로 빨리 누르던 흐름은 느려짐.
- **벨에 너무 많이 모임**: 배지가 15처럼 커지면 결국 무시하게 됨 (다운로드 11개가 대부분). 종류별 우선순위·묶음 배지가 필요.
- **브리핑이 숨음**: 아침에 저절로 보이던 브리핑이 벨 안으로 들어가 안 볼 수도 있음 → 아침 첫 열기 때만 벨에 점을 띄우는 식의 보완 필요.
- **주차별 격자 손실**: 7일 세로 목록은 "한 주 빈 시간" 모양을 한눈에 보기 어렵다. PC 에서는 기존 시간 격자를 다시 쓰는 편이 나을 수 있음.
- **PC 화면 아래가 빔**: 오늘 일정이 짧은 날엔 왼쪽 아래가 비고, 마감 패널만 길다.
- **"지금"과 일정이 겹침**: 지금/다음이 일정 목록 첫 줄과 같은 내용을 두 번 보여 줌 (한눈에 보기의 대가).
- **시트 안 기능 일부는 미구현**: ✍ 보고서 창·📄 자료 찾기 창(검색·둘러보기)은 시안에서 안내만 함. 실제로 옮기면 시트 안에 "다음 화면"으로 넣어야 하고, 시트가 길어짐.
- 이모지 대신 SVG 아이콘이라 기존 버튼 이름(✍·📄·🤖·🧩·🗂)과 모양이 달라 처음엔 낯설 수 있음.
